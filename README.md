## 💡 关于我 (About Me)

你好！我是**秦宇 (QIN YU)**，软件工程专业出身，拥有扎实工程功底的**测试开发工程师 (SDET)**。

- 🎯 **求职意向**：测试开发工程师 / 软件测试工程师 / AI 专项测试工程师（期望地：深圳 / 广州）
- 🔬 **半导体 ATE 上位机测试**：深入参与**车规级芯片测试机（ATE）上位机软件测试**，覆盖功放与功耗芯片的核心控制路径（指令下发、参数配置、数据采集与状态回传），搭建 UI 自动化与长时压测体系。
- 🤖 **AI 与大模型专项评测**：在中金点睛等 Text-to-SQL 项目中确立**「五维验证法」**（问题 → SQL生成 → 结果 → 展示 → 口径），运用 Python (Pandas/NumPy) 攻克大模型生成非结构化数据难以量化校验的痛点。
- 🚀 **自动化测试与工具研发**：熟练掌握 **Python + Pytest + Playwright / Selenium + Allure** 全链路自动化，自研小程序自动化执行引擎与数据分析提效工具，具备结合接口返回、SQL 与日志快速定位 Bug 的过硬排障能力。
- 🐳 **DevOps 与全栈能力**：具备从 0 到 1 落地 Jenkins CI/CD 流水线能力，独立开发 Next.js 15 单一数据源驱动的现代化作品集与测试平台。
