你好！我是**秦宇**，一名追求极致工程质量与效能的**测试开发工程师 (SDET)**。

- 🎯 **求职意向**：测试开发工程师 / 质量保障专家 / AI 专项测试工程师（广州 / 深圳）
- 🚀 **测试开发架构**：擅长从 0 到 1 规划与设计自动化测试体系，深入掌握 **Python + Pytest + Allure** 全链路接口/UI 测试框架，具备自建私有化测试平台与 CI/CD 流水线实战经验。
- 🤖 **AI 与大模型专项**：深入参与 ChatBI 及大模型智能体项目，善于运用 **Pandas / NumPy** 对大模型生成的大规模非结构化数据进行自动化清洗与校验，攻克 AI 评测难以量化对齐的痛点。
- 🔧 **工程效能与全栈能力**：具备独立研发测试工具链的能力（Python / TypeScript / Next.js / Vue），曾独立开发数据构造、日志分析工具与数璇测试平台，用技术手段持续赋能团队测试效能。
- 🐳 **DevOps 交付基建**：熟练掌握 Docker 容器编排、Linux 运维排障及 Jenkins 持续集成自动化触发（Webhook / 钉钉通知）。
